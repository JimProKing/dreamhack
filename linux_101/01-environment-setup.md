# 1. 리눅스 환경 구축

- 강의: [Environment Setup for Linux](https://dreamhack.io/lecture/units/environment-setup-for-linux)
- Path: [Linux 101](https://dreamhack.io/lecture/paths/linux-101)

## 무엇을 배우나

Windows / Mac 에서 **리눅스를 쓰는 방법**을 익힌다.

| 방식 | 설명 |
|------|------|
| **VirtualBox + Ubuntu ISO** | 가상 머신 전체 설치 |
| **WSL2** (Windows) | Windows 안에서 Linux 커널/셸 |
| 드림핵 **Lab** | 브라우저/웹에서 바로 리눅스 터미널 |

## 포인트

- 보안 실습은 대부분 **CLI(터미널)** 기준
- 로컬에 VM을 두면 패키지 설치·네트워크 실험이 편함
- 드림핵 Lab 만으로도 유닛 실습은 가능

## 이 레포 / 내 PC

- Desktop `Download/` 에 Ubuntu ISO, VirtualBox 설치 파일이 있을 수 있음
- 랩: `dreamhack@linux-lab:~$` 프롬프트 = 드림핵 제공 환경
