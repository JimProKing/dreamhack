# SSRF (Server-Side Request Forgery)

## 개념

사용자가 준 URL을 **서버가 대신** 요청한다.  
외부에서 직접 닿지 못하는 **내부 서비스·메타데이터**에 서버 권한으로 접근할 수 있다.

## web-ssrf (#75)

| 요소 | 내용 |
|------|------|
| 기능 | Image Viewer — URL을 받아 응답을 base64 이미지로 표시 |
| 필터 | URL에 `127.0.0.1`, `localhost` 문자열 포함 시 차단 |
| 내부 | loopback의 **1500–1800** 랜덤 포트에서 flag 제공 |
| 플래그 | 예: `/flag.txt` |

### 절차

1. IP 표기 우회: `127.0.0.1` → **`2130706433`** (동일 주소의 10진 표기)

```text
http://2130706433:PORT/flag.txt
```

2. `PORT` ∈ [1500, 1800] 탐색 (응답 길이·내용이 다른 포트)
3. 뷰어에 실린 base64를 디코드 → `DH{...}`

### 스크립트 주의

- `HOST`에 오타·비ASCII 문자 금지
- 폼은 보통 `POST /img_viewer`, 필드 `url`
- error.png(PNG 시그니처)와 flag 텍스트 응답 구분

## CSRF와의 구분

| | CSRF | SSRF |
|--|------|------|
| 누가 요청하나 | **피해자 브라우저** | **서버** |
| 전형적인 목표 | 피해자 권한 액션 | 내부망·내부 포트 |
