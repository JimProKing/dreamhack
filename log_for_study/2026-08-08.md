## 큰 그림

```text
정보보안이 뭔가 (CIA, 일상)
  → 사람을 속임 (사회공학·피싱)
  → 코드가 해침 (악성코드·랜섬)
  → 계정을 지킴 (인증·비번·MFA)
  → 새 도구 위협 (AI/LLM)
  → 데이터가 흐름 (저장·공유·삭제)
  → 공간도 경계 (물리)
```

워게임과 역할 분담:

| 축 | 하는 일 |
|----|---------|
| 이 Path | 왜 사고가 나는지, 평소·대응 |
| web / war_game | 구멍이 기술적으로 어떻게 도는지 |

둘 다 있어야 “클릭 조심” + “왜 그 클릭이 위험한지” 가 맞음.
