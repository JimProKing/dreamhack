### 1. Netcat (nc / ncat)

**무엇인가**

- 네트워크 스위스 아미 나이프 — TCP(·UDP)로 읽고 쓰기
- 서버에 붙는 **클라이언트**, 포트 열어서 기다리는 **리스너** 둘 다 가능
- 드림핵: 브라우저 URL이 아니라 **바이너리 서비스**일 때 자주 사용

**기본 사용**

```bash
nc host port
# Windows (Nmap 번들): ncat host port
ncat host3.dreamhack.games 12902
```

**드림핵 흐름:** 서버 생성 → host/port 확인 → `ncat host port` → 프롬프트 입력 → 플래그

**실습:** [Welcome-Beginners (#812)](https://dreamhack.io/wargame/challenges/812) — `Dreamhack` 입력

**자동화:** 시간 제한 등은 pwntools `remote(host, port)` 로 동일 통신 스크립트화.

```python
from pwn import *
p = remote('host3.dreamhack.games', 12902)
p.sendlineafter(b': ', b'Dreamhack')
print(p.recvall(timeout=2))
```

| Windows 도구 | 비고 |
|--------------|------|
| `ncat` | Nmap 설치 시 포함 |
| `nc` | 환경에 따라 없음 |
| pwntools | venv + `pip install pwntools` |

### 2. SSH (Secure Shell)

**무엇인가**

- 암호화된 원격 접속 프로토콜
- 원격 리눅스에 로그인해서 셸·파일 작업
- 비밀번호 또는 개인키(`-i`) 인증

**기본 사용**

```bash
ssh user@HOST -p PORT
ssh user@HOST -p PORT -i 개인키경로
```

| 부분 | 의미 |
|------|------|
| `user` | 서버 계정 (예: `chall`) |
| `HOST` | 도메인/IP |
| `-p PORT` | SSH 포트 (기본 22가 아닐 때 필수) |

```bash
ssh chall@host3.dreamhack.games -p 13277
# password: (문제에서 준 값, 예: dhbgssh)
```

**흐름:** 서버 생성 → `ssh id@host -p port` → fingerprint `yes` → 비밀번호 → `ls` / `cat flag` → `exit`

**실습:** [Exercise: SSH (#875)](https://dreamhack.io/wargame/challenges/875) — id `chall` / pw `dhbgssh`

```powershell
Get-WindowsCapability -Online | Where-Object Name -like 'OpenSSH.Client*'
# State : Installed 이면 ssh 사용 가능
```

### 4. Docker

**개념**

```text
Dockerfile (설계도) → docker build → Image (템플릿)
                              ↓ docker run
                         Container (실행 인스턴스)
```

| 용어 | 의미 |
|------|------|
| **Dockerfile** | 이미지 만드는 지시서 |
| **Image** | 읽기 전용 스냅샷 (레이어 쌓임) |
| **Container** | 이미지를 실행한 프로세스/환경 |
| **Layer** | 빌드 단계별 FS 조각. 삭제해도 이전 레이어에 남을 수 있음 |

**자주 쓰는 명령**

```bash
docker version / docker info     # 엔진 동작 (Server 필요)
docker pull 이미지:태그
docker build -t 이름 .           # 현재 폴더 Dockerfile
docker images
docker run -it 이미지 /bin/bash
docker ps / docker ps -a
docker stop / docker rm / docker rmi
docker save 이미지 -o out.tar    # 레이어 분석용
```

| 옵션 | 의미 |
|------|------|
| `-t 이름` | 이미지 태그 |
| `-it` | 대화형 터미널 |
| `-p 호스트:컨테이너` | 포트 연결 |
| `--rm` | 종료 시 컨테이너 삭제 |

**Windows:** Docker Desktop 실행 → `docker version` 에 **Server** 줄 확인

| 문제 | 할 일 |
|------|--------|
| [Exercise: Docker (#876)](https://dreamhack.io/wargame/challenges/876) | 로컬 **build** → `run` → `cat flag` |
| [blue-whale (#853)](https://dreamhack.io/wargame/challenges/853) | `pull ...:1` 후 **레이어 분석** (dive / `solve.ps1`) |

```bash

```

### 5. 정규표현식 (Regex)

문자열에서 **패턴**을 찾거나 검사·치환. 웹 입력 검증, 필터 우회 문제에 자주 등장.

| 기호 | 의미 |
|------|------|
| `.` | 아무 문자 1개 (개행 제외 기본) |
| `\w` | `[A-Za-z0-9_]` |
| `\d` | 숫자 |
| `\s` | 공백 |
| `*` / `+` / `?` | 0회 이상 / 1회 이상 / 0·1회 |
| `{n}` `{n,m}` | n회 / n~m회 |
| `[a-z]` `[^0-9]` | 집합 / 부정 |
| `^` `$` | 시작 / 끝 |
| `\.` | 이스케이프 (문자 그대로) |
| `\|` `(...)` | OR / 그룹 |

```python
import re
re.match(r'패턴', s)    # 앞부터
re.search(r'패턴', s)   # 중간도
re.sub(r'패턴', '치환', s)
```

```php
preg_match("/패턴/", $s);
preg_replace("/패턴/i", "", $s);  // i = 대소문자 무시
```

연습: [regexr.com](https://regexr.com/), [regexper.com](https://regexper.com/), CyberChef Regular expression  
수량자·플래그 등 더 자세한 표는 아래 **강의: 정규표현식 (#461)** 절.

| 문제 | 접근 |
|------|------|
| [ex-reg-ex (#834)](https://dreamhack.io/wargame/challenges/834) | 패턴에 **맞는** 문자열 — `drabcdee1am@abc.com` |
| [phpreg (#873)](https://dreamhack.io/wargame/challenges/873) | 필터 **우회** — 닉/비번 + `cat ../dream/????.txt` |

## 워게임: Exercise: SSH (#875)

- 링크: https://dreamhack.io/wargame/challenges/875
- 카테고리: Beginner (실습)
- 난이도: 입문
- 정리: `war_game/exercise-ssh_875/`

### 문제 요지

SSH 실습 문제. 문제 서버에 SSH로 접속한 뒤 홈 디렉터리의 `flag` 파일을 읽으면 된다.  
플래그 형식: `DH{...}`

문제에서 주는 계정 정보:

| 항목 | 값 |
|------|-----|
| id | `chall` |
| password | `dhbgssh` |

### 풀이 흐름

| 단계 | 할 일 |
|------|--------|
| 1 | **서버 생성하기** → host / port 확인 |
| 2 | `ssh chall@host -p 포트` 로 접속 |
| 3 | 처음이면 fingerprint 물어봄 → `yes` |
| 4 | password: `dhbgssh` (입력 중 화면엔 안 보임) |
| 5 | `ls` → `cat flag` → `DH{...}` 제출 |

### Windows OpenSSH 확인

이 노트북에 OpenSSH Client가 이미 설치되어 있었음.

```powershell
Get-WindowsCapability -Online | Where-Object Name -like 'OpenSSH.Client*'
# Name  : OpenSSH.Client~~~~0.0.1.0
# State : Installed
```

### 실제 접속 기록 (이 노트북)

```text
ssh chall@host3.dreamhack.games -p 13277
# fingerprint → yes
# password → dhbgssh
ls
# bin  flag
cat flag
# DH{h3110_6e9inn3rs!}
```

- 도구: Windows OpenSSH (`ssh`)
- 포트: `13277` (인스턴스마다 다름)
- 플래그: `DH{h3110_6e9inn3rs!}`

### 명령어 의미

```text
ssh chall@host3.dreamhack.games -p 13277
```

| 부분 | 의미 |
|------|------|
| `ssh` | Secure Shell — 원격 서버에 암호화된 셸 접속 |
| `chall@호스트` | 사용자 `chall` 로 해당 호스트 접속 |
| `-p 13277` | SSH 포트 (기본 22가 아니라 드림핵이 준 포트) |

접속 후 자주 쓰는 리눅스 명령: `ls`, `cat flag`, `exit`

### 주의

- 문제 파일로 받은 `flag` 는 **가짜**인 경우가 많음. 진짜는 **서버 안**에 있음.
- 비밀번호 입력 시 커서가 안 움직여도 정상.
- fingerprint `yes` 하면 `known_hosts` 에 저장됨.

### 문제 요지

Docker 실습. 주어진 `Dockerfile`을 빌드해 이미지를 만들고, 컨테이너를 실행한 뒤 안의 `flag`를 읽는다.  
플래그 형식: `DH{...}`

### 개념

```text
Dockerfile (설계도) → docker build (이미지) → docker run (컨테이너) → cat flag
```

| 개념 | 역할 |
|------|------|
| **Dockerfile** | 이미지 만드는 설계도 |
| **Image** | 빌드 결과 템플릿 |
| **Container** | 이미지를 실제로 실행한 인스턴스 |

### 풀이 흐름

| 단계 | 할 일 |
|------|--------|
| 1 | Docker Desktop 실행 |
| 2 | `docker version` / `docker info` 로 동작 확인 |
| 3 | 문제 파일 다운로드 → 압축 해제 (`Dockerfile`, `deploy/`) |
| 4 | 그 폴더에서 `docker build -t dreamhack-docker .` |
| 5 | `docker run -it dreamhack-docker /bin/bash` |
| 6 | 컨테이너 안: `ls -al` → `cat flag` → 제출 |

### 실제 풀이 기록 (이 노트북)

- 플래그: `DH{docker_exercise}`

### Dockerfile이 하는 일 (요약)

문제 `Dockerfile` 요지:

- 베이스: `ubuntu:22.04`
- `socat` 설치, 사용자 `chall` 생성
- `deploy/flag`, `deploy/chall` 을 `/home/chall/` 에 복사
- 권한 설정 후 `WORKDIR /home/chall`
- 기본 CMD는 socat으로 바이너리 서비스 (이 문제는 **셸로 들어가 `cat flag`** 해도 됨)

### 명령어 의미

```powershell
docker build -t dreamhack-docker .
docker run -it dreamhack-docker /bin/bash
```

## 강의: 정규표현식 (learn #461)

- 링크: https://learn.dreamhack.io/461
- 워게임 연결: [ex-reg-ex (#834)](https://dreamhack.io/wargame/challenges/834)
- 문제 정리: `war_game/ex-reg-ex_834/`

### 정규표현식이란

**정규표현식 (Regular Expression, Regex)**  
문자열에서 **특정 패턴**을 찾거나, 맞는지 검사하거나, 치환할 때 쓰는 “규칙 언어”.

| 용도 | 예 |
|------|-----|
| 검증 | 입력이 이메일/아이디 형식인지 |
| 검색 | 로그에서 IP·에러 코드만 뽑기 |
| 치환 | 패턴에 맞는 부분 바꾸기 |
| 웹/필터 | 입력 검사, WAF, 소스 코드 `re.match` 등 |

보안·워게임에서는 **필터를 우회**하거나, 반대로 **필터가 요구하는 형식**을 맞춰 플래그를 받는 문제(#834)로 자주 나옴.

### 연습 도구 (강의에서 소개하는 종류)

| 도구 | 용도 |
|------|------|
| [regexr.com](https://regexr.com/) | 패턴 작성 + 매치 확인 + 설명 |
| [regexper.com](https://regexper.com/) | 정규식 **시각화** (도식) |
| [Dreamhack CyberChef](https://tools.dreamhack.games/cyberchef) | Operations → **Regular expression** |

### 수량자 (앞에 있는 것을 몇 번?)

| 기호 | 의미 | 예 (`lo` + 수량 + `ve`) |
|------|------|-------------------------|
| `*` | 0개 이상 | `lve`, `love`, `loove` … |
| `+` | 1개 이상 | `love`, `loove` (lve 불가) |
| `?` | 0개 또는 1개 | `lve`, `love` |
| `{n}` | 정확히 n개 | `lo{2}ve` → `loove` |
| `{n,}` | n개 이상 | `lo{2,}ve` → `loove`, `looove` … |
| `{n,m}` | n개 이상 m개 이하 | `lo{1,2}ve` → `love`, `loove` |
| `(...)` | 그룹 (묶어서 수량 적용) | `(lo)+` → `lo`, `lolo` … |

### 매치 / 메타문자

| 기호 | 의미 | 예 |
|------|------|-----|
| `.` | 거의 아무 문자 1개 (개행 제외 기본) | `lo.e` → `love`, `lose` |
| `\|` | 또는 (OR) | `a\|b` → a 또는 b |
| `[abc]` | a 또는 b 또는 c 중 하나 | `[aeiou]` 모음 |
| `[^abc]` | a,b,c **제외** | |
| `[a-z]` | a~z 범위 | 소문자 |
| `[A-Z]` | 대문자 | |
| `[0-9]` | 숫자 = `\d` | |
| `^` | **문자열 시작** (대괄호 안에서는 부정) | `^dr` → dr로 시작 |
| `$` | **문자열 끝** | |
| `\` | 이스케이프 (특수문자를 글자 그대로) | `\.` → 진짜 점 `.` |
| `\w` | 단어 문자 = `[A-Za-z0-9_]` | |
| `\d` | 숫자 = `[0-9]` | |
| `\s` | 공백 | |

### Greedy vs Lazy

| | 의미 |
|--|------|
| **Greedy** (기본) | 가능한 한 **많이** 먹음 (`*`, `+` 등) |
| **Lazy** | 수량자 뒤에 `?` → 가능한 한 **적게** (`*?`, `+?`) |

### 플래그 (언어/도구마다 표기 다름)

| 플래그 | 의미 | Python `re` 예 |
|--------|------|----------------|
| `i` | 대소문자 무시 | `re.I` |
| `m` | 여러 줄 (`^` `$`가 줄 단위) | `re.M` |
| `s` | `.`이 개행도 포함 | `re.S` |
| `g` | 전부 찾기 (JS 등; Python은 `findall`) | |

### Python `re` 모듈 (웹 문제에 자주 나옴)

```python
import re

re.match(pattern, string)   # 문자열 **앞부터** 패턴이 맞는지
re.search(pattern, string)  # 문자열 **아무 위치**에서 검색
re.findall(pattern, string) # 맞는 부분 전부 리스트
re.fullmatch(pattern, string)  # 전체 문자열이 패턴과 일치
```

| 함수 | 특징 |
|------|------|
| **`match`** | 맨 앞에서만 검사 (#834 가 이거 사용) |
| **`search`** | 중간에도 있으면 OK |
| **`fullmatch`** | 처음부터 끝까지 전부 일치해야 함 |

패턴 앞에 `r'...'` (raw string) 쓰면 백슬래시 이스케이프가 편함.

```python
m = re.match(r'dr\w{5,7}e\d+am@[a-z]{3,7}\.\w+', input_val)
if m:  # 매치 성공하면 truthy
    ...
```

## 워게임: ex-reg-ex (#834)

- 링크: https://dreamhack.io/wargame/challenges/834
- 카테고리: Web / Beginner
- 강의 연계: [learn #461 정규표현식](https://learn.dreamhack.io/461)
- 정리: `war_game/ex-reg-ex_834/`

### 문제 요지

요구 형식(정규식)에 맞는 문자열을 입력하면 플래그.  
플래그는 서버의 `flag.txt` / `FLAG` 변수. 형식 `DH{...}`.

### 문제 파일

다운로드하면 **`app.py`만** 있는 경우가 많음 → **정상**.

- `index.html`, 진짜 `flag.txt` 는 **드림핵 서버 안**에 있음  
- 로컬 `python app.py` 는 정석 아님 (템플릿 없으면 `TemplateNotFound`)  
- `app.py` 는 **정규식 읽는 용도**

### 핵심 코드

```python
m = re.match(r'dr\w{5,7}e\d+am@[a-z]{3,7}\.\w+', input_val)
if m:
    return render_template("index.html", pre_txt=input_val, flag=FLAG)
return render_template("index.html", pre_txt=input_val, flag='?')
```

### 정규식 분해 + 예시 입력

```text
패턴:  dr \w{5,7} e \d+ am@ [a-z]{3,7} \. \w+
입력:  dr  abcde   e  1  am@  abc       .  com
       ───────────────────→  drabcdee1am@abc.com
```

| 조각 | 의미 | 예시 부분 |
|------|------|-----------|
| `dr` | 고정 | `dr` |
| `\w{5,7}` | 단어 문자 5~7개 | `abcde` |
| `e` | 고정 | `e` |
| `\d+` | 숫자 1개 이상 | `1` |
| `am@` | 고정 | `am@` |
| `[a-z]{3,7}` | 소문자 3~7개 | `abc` |
| `\.` | 점 `.` | `.` |
| `\w+` | 단어 문자 1개 이상 | `com` |

**헷갈리기 쉬운 점:** 화면에는 `drabcdee` 가 이어져 보이지만  
`dr` + `abcde` + `e` 세 덩어리.

다른 예: `dr12345e99am@hack.k`, `drabcdefe123am@xyz.io`

### 정석 풀이 순서

1. 문제 파일 다운로드 → **`app.py`만 읽고** 정규식 파악  
2. 패턴에 맞는 문자열 작성 (예: `drabcdee1am@abc.com`)  
3. 드림핵 **서버 생성**  
4. 브라우저로 `http://host:port` 접속 (웹 문제)  
5. 입력란에 문자열 제출 → `DH{...}` 복사  
6. 문제 페이지 FLAG 제출  

로컬 서버/연습용 템플릿은 **선택**. 제출용 플래그는 **원격 서버**에서.

### 강의 개념 ↔ 이 문제

| 강의 개념 | #834 에서 |
|-----------|-----------|
| `\w`, `\d`, `[a-z]` | 패턴 구성 요소 |
| `{5,7}`, `+` | 반복 횟수 |
| `\.` | 특수문자 이스케이프 |
| `re.match` | 앞부터 매치되면 플래그 |
| 검증용 regex | “맞는 입력”을 만들어 통과 |

### Step 1 — Nickname / Password 어떻게 확인?

최종 목표 (`step2.php`):

```php
if ($name === "dnyang0310" && $pw === "d4y0r50ng+1+13")
```

필터 때문에 그대로 입력하면 안 됨.

#### Nickname

```php
$name = preg_replace("/nyang/i", "", $input_name);
```

- `dnyang0310` → `nyang` 삭제 → `d0310` 실패  
- 우회: `dnnyangyang0310` → 삭제 후 `dnyang0310`

#### Password

```php
// 영문 금지
preg_match("/[a-zA-Z]/", $input_pw)
// 패턴 매치면 d4y0r50ng 로 치환
preg_replace("/\d*\@\d{2,3}(31)+[^0-8\"]\!/", "d4y0r50ng", $input_pw)
```

- 패턴 예: `0@12319!` → `d4y0r50ng`  
- 최종: `0@12319!+1+13` → `d4y0r50ng+1+13`

#### Step 1 입력값

| 필드 | 값 |
|------|-----|
| Nickname | `dnnyangyang0310` |
| Password | `0@12319!+1+13` |

### Step 2 — Command에 뭐 입력?

```php
if (preg_match("/flag/i", $cmd)) { Error }
else { system($cmd); }
```

| 안 됨 | 됨 |
|-------|-----|
| `cat ../dream/flag.txt` (`flag` 단어) | `cat ../dream/????.txt` |
| | `cat ../dream/*` |

`?` = 셸 와일드카드(문자 1개).

