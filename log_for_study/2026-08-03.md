## pwntools 정리

참고: Dreamhack Tool: pwntools 강의 + [공식 문서](https://docs.pwntools.com/)

### 왜 쓰나

- 익스플로잇/워게임에서 자주 하는 일(프로세스 붙기, 데이터 주고받기, 패킹 등)을 매번 직접 짜기 귀찮음
- 그걸 모아 둔 파이썬 라이브러리
- 거의 모든 시스템 해킹 스크립트 예제가 pwntools 기준

### 설치 (mac 기준, 내가 겪은 것)

Homebrew python은 시스템 전체에 pip 설치를 막는 경우가 있음 (`externally-managed-environment`).

그래서 가상환경 쓰는 게 맞음. 나는 Python 3.12로 venv 만듦. (3.14는 unicorn 빌드 깨져서 실패했음)

```bash
python3.12 -m venv venv
source venv/bin/activate
pip install pwntools
python -c "from pwn import *; print('ok')"
```

### 1. process / remote — 대상에 연결

| 함수 | 용도 |
|------|------|
| `process('./bin')` | 로컬 바이너리 실행 후 통신 (테스트/디버깅) |
| `remote(host, port)` | 원격 서버 TCP 연결 (드림핵 워게임 서버) |

```python
p = process('./chall')
p = remote('host3.dreamhack.games', 12771)
```

- Dreamhack 포트 표기: `12771/tcp → 31337/tcp`
  - **왼쪽**이 밖에서 접속하는 포트 → `remote`에 이걸 넣음
  - 오른쪽은 컨테이너 내부 포트

process / remote 둘 다 같은 송수신 API 씀. 로컬에서 맞춘 뒤 remote만 바꾸면 됨.

### 2. send 계열 — 데이터 보내기

| 함수 | 동작 |
|------|------|
| `send(data)` | 그대로 전송 |
| `sendline(data)` | `data + '\n'` 전송 (scanf / input 쓸 때 자주 씀) |
| `sendafter(delim, data)` | `delim` 출력 나올 때까지 읽고 나서 `data` 전송 |
| `sendlineafter(delim, data)` | 위와 같되 개행 포함해서 전송 |

```python
p.send(b'AAAA')
p.sendline(b'1234')
p.sendlineafter(b'> ', b'2')
```

python3에서는 네트워크 데이터가 **bytes** 기준이라 `b'...'` / `.encode()` 자주 씀.

### 3. recv 계열 — 데이터 받기

| 함수 | 동작 |
|------|------|
| `recv(n)` | 최대 n바이트 (부족해도 올 수 있음) |
| `recvn(n)` | **정확히** n바이트 올 때까지 대기 |
| `recvline()` | 개행(`\n`)까지 |
| `recvuntil(delim)` | `delim` 나올 때까지 |
| `recvall()` | 프로세스/연결 끝날 때까지 전부 |

```python
data = p.recvuntil(b'+', drop=True)  # drop=True → 구분자는 버림
line = p.recvline()
flag = p.recvall(timeout=2)
```

**recv vs recvn**
- `recv(n)`: 최대 n, 모자라도 에러 안 남
- `recvn(n)`: 정확히 n 받을 때까지 기다림

오늘 문제에서 많이 쓴 패턴:

```python
# "3142+8901=?"
num1 = int(p.recvuntil(b'+', drop=True))
num2 = int(p.recvuntil(b'=?\n', drop=True))

# "2. flag"
data = p.recvuntil(b'. flag', drop=True)
idx = data.decode()[-1]
```

### 4. packing / unpacking

주소를 페이로드에 넣을 때 정수를 **리틀 엔디언 바이트**로 바꿔야 함.

| 함수 | 의미 |
|------|------|
| `p32(x)` / `p64(x)` | 정수 → 4/8바이트 바이트열 (pack) |
| `u32(b)` / `u64(b)` | 바이트열 → 정수 (unpack) |

```python
p64(0x4005a7)   # b'\xa7\x05\x40\x00\x00\x00\x00\x00'
u32(b'DCBA')    # 0x41424344
```

빅 엔디언이 필요하면 `endian='big'` 옵션.

아직 워게임 misc만 풀어서 오늘은 거의 안 썼지만, pwn 가면 필수.

### 5. interactive

셸 먹었거나, 직접 타이핑하면서 보고 싶을 때.

```python
p.interactive()
```

호출하면 터미널이 그 프로세스/서버에 붙음.

### 6. ELF

바이너리 정보 뽑을 때.

```python
e = ELF('./chall')
addr = e.symbols['get_shell']
plt_puts = e.plt['puts']
got_read = e.got['read']
```

- `symbols`: 함수/전역 심볼 주소
- `plt` / `got`: PLT, GOT 주소 (나중에 ROP 등에서 씀)
- `search(b'str')`: 문자열 주소 찾기

### 7. context

전역 설정.

```python
# 로그 레벨
context.log_level = 'debug'  # 주고받는 데이터 전부 출력 (디버깅 꿀)
context.log_level = 'info'   # 기본에 가깝게
context.log_level = 'error'  # 에러만

# 아키텍처 (셸코드/asm/패킹 기본값에 영향)
context.arch = 'amd64'  # x86-64
context.arch = 'i386'
context.arch = 'arm'
```

안 풀릴 때 일단 `debug` 켜보는 습관 들이기.

### 8. shellcraft / asm

```python
context.arch = 'amd64'
code = shellcraft.sh()   # 셸 띄우는 셸코드 (어셈 문자열)
raw = asm(code)          # 기계어 바이트로 변환
```

제약(길이, bad char 등) 있으면 그대로 못 쓸 수도 있음. 그때는 직접 짜야 함.
