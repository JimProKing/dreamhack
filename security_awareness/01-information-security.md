## 정보보안

**정보**를 지켜야 할 때 자주 쓰는 세 축 (CIA):

| | 이름 | 뜻 |
|--|------|-----|
| C | Confidentiality | 허락된 사람만 봄 |
| I | Integrity | 위·변조 없이 믿을 수 있음 |
| A | Availability | 필요할 때 쓸 수 있음 |

일상에도 해당: 메신저 대화, 사진, 회사 문서, 계정.

보안이 “안 보이는” 이유: 사고 나기 전엔 티가 안 남.  
실수는 작아 보여도 (링크 클릭, USB, 약한 비번) 큰 사고로 이어질 수 있음.

## 해킹 (입문 관점)

허가 없이 시스템·정보를 다루려는 행위.  
학습·방어 목적의 합법 범위(워게임, 버그바운티 규칙)와 불법 침해는 선이 다름.

이 Path + 드림핵 워게임 = **합법 연습장**에서 원리 익히기.

## Lab: IDOR (감만)

**IDOR** = 권한 검사 없이 다른 사람 자원 ID만 바꿔 접근하는 유형.

예: `/user?id=1` (나) → `id=2` (남) 로 바꿔도 응답이 옴.

| 관찰 | 의미 |
|------|------|
| 인증만 있고 인가 없음 | “로그인했냐”만 보고 “이 데이터 네 거냐” 안 봄 |
| 워게임 연결 | 쿠키·세션 위조, 권한 상승 문제와 같은 뿌리 |
