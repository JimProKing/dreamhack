# 5. AI · LLM 보안

- 유닛: [AI and LLM Security](https://dreamhack.io/lecture/units/ai-and-llm-security)

## 생성형 AI가 바꾸는 것

- 코드·문서·피싱 문장 생성 비용 ↓  
- 딥페이크·사칭 난이도 ↓  
- 업무에 LLM API·챗봇 붙는 경우 ↑  

## 위협 감각

| 쪽 | 예 |
|----|-----|
| 공격자가 AI 씀 | 더 그럴듯한 피싱, 악성 코드 초안, 대량 자동화 |
| AI를 씀 | 민감 정보 프롬프트에 붙여넣기 → 유출 |
| AI 서비스 자체 | 프롬프트 인젝션, 잘못된 답(환각) 신뢰, 권한 과다 툴 연결 |

## 안전하게 쓰는 쪽

- 회사 비밀·고객 개인정보·키·토큰을 사내 정책 없이 외부 LLM에 넣지 않기  
- 답이 **사실처럼 보여도** 중요 결정은 검증  
- 플러그인·툴 연동 시 “이 봇이 어디까지 접근하나” 확인  
- 피싱: “AI가 쓴 문장”이라 어색함이 줄어듦 → **발신·URL·공식 경로** 더 보기
