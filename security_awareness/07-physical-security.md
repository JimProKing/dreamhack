# 7. 물리 보안

- 유닛: [Physical Security](https://dreamhack.io/lecture/units/physical-security)

## 뭔지

디지털만이 아니라 **몸·공간·물건**으로 정보가 새는 것.

| 예 | |
|----|--|
| 테일게이팅 | 출입 통과하는 사람 따라 들어가기 |
| 자리 비움 | 잠금 안 한 PC, 서류 펼침 |
| 어깨 너머 | 비밀번호·화면 훔쳐보기 |
| 매체 | USB, 출력물, 폐기 HDD |
| 기기 분실 | 노트북·휴대폰 잠금·원격 초기화 |

## 일상·업무

- 자리 비울 때 잠금 (Win+L 등)  
- 민감 출력물 방치 X, 파쇄  
- 출입 카드 대여·문 잡아주기 주의  
- 회의실 화이트보드·줌 화면  
- 공용 PC·호텔 비즈니스 센터  

사회공학(사람) + 물리(공간) 가 자주 세트로 감.
