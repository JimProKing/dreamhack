# 2. 사회공학 (Social Engineering)

- 유닛: [Social Engineering](https://dreamhack.io/lecture/units/social-engineering)
- Lab: Phishing Prevention · Quiz 포함

## 뭔지

시스템을 뚫기 전에 **사람**을 속이는 쪽.  
방화벽보다 “급해요, 클릭 좀” 이 더 잘 먹을 때가 있음.

## 크게 나누면

| 유형 | 예 |
|------|-----|
| **사람 대 사람** | 전화로 사칭, 위장 방문, 테일게이팅(따라 들어가기) |
| **컴퓨터 매개** | 피싱 메일/문자, 가짜 사이트, 악성 첨부 |

## 피싱 (자주 나옴)

| 신호 | |
|------|--|
| 급박함·공포 (“계정 정지”) | 이성 마비용 |
| 보낸 사람·도메인 미묘한 오타 | |
| 짧은 링크, 수상한 첨부 | |
| “지금 당장 로그인/이체” | |

Lab: 피싱 예방 훈련 — 의심 메일 고르기, 공식 경로로 다시 확인.

## 막는 쪽

- 공식 앱·북마크로 직접 들어가서 확인  
- 요청이 이상하면 다른 채널로 재확인 (전화 → 메신저로 “방금 전화 왔어요?”)  
- 모르는 첨부·매크로 실행 안 함  
- 회사: 신고 채널 알기
