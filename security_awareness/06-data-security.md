# 6. 데이터 보안

- 유닛: [Data Security](https://dreamhack.io/lecture/units/data-security)

## 기본

데이터가 **어디서 → 어디로 → 얼마나 오래 → 누가** 보는지.

| 단계 | 생각 |
|------|------|
| 수집 | 꼭 필요한 것만 |
| 저장 | 암호화, 접근 권한, 백업 |
| 이용·공유 | 최소 권한, 채널 안전한지 |
| 삭제 | 휴지통·클라우드 잔존, 매체 폐기 |

## 협업할 때

- 링크 공유 범위 (조직 / 링크 있는 사람 전원)  
- 잘못 붙은 권한 (편집 vs 보기)  
- 개인 메신저로 회사 파일 던지기  
- 화면 공유 중 다른 탭·알림  

## 사내

- 등급·라벨 (공개 / 내부 / 비밀)  
- USB·개인 클라우드 정책  
- 퇴사·기기 반납 시 데이터  
- 유출 사고 시 보고 라인  

## 워게임이랑

다운로드 취약·SSRF·웹쉘 = 결국 **데이터가 잘못된 길로 나감**.  
기술 구멍 + 잘못된 공유 습관이 겹치면 사고.

---

## 한 줄

> 데이터 보안 = 암호화 한 방이 아니라 **생명주기 전체** (만들고, 나누고, 지울 때까지).
